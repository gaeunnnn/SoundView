프로젝트 아이디어 조사 및 구체화

마피아게임 (가제)
프로젝트 개요
AI 실시간 음성 복제 기술을 활용하여 플레이어를 사칭하고 속이는 차세대 심리 추리 마피아 게임입니다. 대기실에서 수집된 플레이어들의 음성 데이터를 AI가 학습(Voice Cloning)하며, 게임 중 특정 플레이어의 목소리를 복제하여 가짜 정보를 전달하는 등 청각적 기만 요소를 핵심 메커니즘으로 활용합니다.

기술 스택
Frontend
React / Next.js: 사용자 인터페이스(UI) 및 실시간 게임 화면 구현

Backend
Node.js (Express): 게임 로직 제어 및 서버 측 API 관리

Redis: 실시간 세션 관리 및 유저 상태 정보 저장

Real-time Communication
WebRTC / Socket.io: 저지연 음성 채팅 및 실시간 데이터 동기화

Artificial Intelligence
AI - Voice: ElevenLabs API / RVC (Zero-shot 실시간 음성 복제 및 목소리 변조)

AI - Text: Gemini API / OpenAI (게임 상황에 맞는 사칭 대본 및 방해 멘트 생성)

Infrastructure
AWS / Docker: 서비스 호스팅 및 AI 모델 서빙 최적화

핵심 기능 (MVP)
1. 실시간 보이스 클로닝 (Zero-shot Voice Conversion)
게임 시작 전 수집된 유저의 짧은 음성 샘플을 기반으로 즉각적인 목소리 복제 모델 생성

2. 사칭 특수 스킬 시스템
마피아 및 스파이 전용 UI를 통해 사칭 타겟을 선택하고, 자신의 음성을 타겟의 목소리로 실시간 변조하여 송출

3. 청각적 및 시각적 기만 연출
사칭 음성 송출 시, 실제 사칭 대상의 프로필 아이콘을 활성화하여 시각적으로도 완벽한 사칭 구현

4. WebRTC 기반 저지연 음성 채팅
변조된 음성과 일반 음성이 끊김 없이 혼합되어 들릴 수 있는 안정적인 대화 환경 구축

5. 기본 마피아 게임 로직
역할 배정(마피아, 시민, 경찰, 의사 등), 낮과 밤의 페이즈 전환, 투표 및 처형 시스템

실현 가능성 및 도전 과제
실현 가능성
음성 복제 기술: ElevenLabs API 또는 오픈소스 RVC, VITS 모델을 활용하여 10초 내외의 샘플만으로 자연스러운 목소리 복제 가능

상황 인지 대본 생성: LLM(Gemini)에 현재 생존자 목록과 게임 상태를 컨텍스트로 제공하여 교묘한 방해 멘트 실시간 생성 가능

도전 과제
기술적 관건: TTS(텍스트-음성 변환) 및 음성 변조 시 발생하는 지연 시간(Latency)을 최소화하여 실시간 대화 흐름을 유지하는 것이 핵심 과제'

 

양자화(Quantization) 개념
정의: 모델의 가중치를 fp16(16-bit)에서 4-bit 등 낮은 비트로 변환하여 모델을 경량화하는 기법입니다.

목적: 성능 하락을 최소화하면서 모델 사이즈를 줄여 낮은 VRAM 환경에서도 학습 및 추론이 가능하게 합니다.

QLoRA (Quantized LoRA) 실습
특징: 4-bit 양자화된 베이스 모델 위에 LoRA(Low-Rank Adaptation) 학습 방식을 적용하여 효율적으로 파인튜닝을 진행했습니다.

평가 지표: evaluation.py를 활용해 SQL 생성 능력(Text-to-SQL)의 정확도를 측정했습니다.

Execution Accuracy: 실제 DB에서 SQL을 실행했을 때의 정확도로 모델의 실질적인 성능을 검증했습니다.
