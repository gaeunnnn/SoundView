# [TIL] 2026-02-26: 청각장애인을 위한 목소리 억양 시각화 - STT 음절 단위 분할의 한계와 해결책

## 🤔 오늘 마주한 문제 (Problem)
청각장애인 분들이 상대방의 말의 높낮이(억양)를 직관적으로 파악할 수 있도록, 음성 인식(STT) 텍스트를 피치(Pitch)에 맞춰 위아래로 춤추듯 시각화하는 기능을 구현하고자 했다.

처음에는 Whisper STT가 반환하는 단어 단위의 타임스탬프를 **글자 수만큼 시간(1/n)으로 나누어** 피치 데이터를 매핑하려 했다. 하지만 치명적인 오류가 발생했다.
* **시간 분할의 오류:** 사람은 기계처럼 모든 음절을 똑같은 길이로 발음하지 않는다. 어떤 글자는 길게 끌고 어떤 글자는 짧게 내뱉는데, 무작정 시간으로 등분하니 실제 발음과 시각화된 억양 높낮이가 완전히 따로 노는 현상이 발생했다.
* **마이크 노이즈와 미세 떨림:** 사람의 목소리는 일정한 톤을 유지해도 미세하게 떨린다. 이 떨림을 모두 상승/하강으로 표시하니 화면이 너무 요동쳐 가독성을 심각하게 해쳤다.

## 💡 고민의 결과 및 해결책 (Solution)

### 1. 절대적 '시간' 분할 포기 -> '유효 데이터' 분할 적용
시간을 기준으로 글자를 쪼개는 것이 현실적으로 불가능하고 효과도 미비하다는 결론을 내렸다.
대신, `librosa.pyin`으로 추출한 데이터 중 무음/침묵(NaN)을 제거한 **'진짜 성대 떨림(Valid Pitch)' 데이터만 수집**했다. 그리고 이 진짜 목소리 데이터 배열을 글자 수만큼 `np.array_split`으로 공평하게 N등분하여 각 글자에 할당했다.

### 2. 억양 판별 민감도(Threshold) 둔화
미세한 떨림을 무시하기 위해 상승/하강 판별 기준을 `5Hz`에서 `10Hz`로 대폭 상향했다. 
명확하게 끝을 올리거나 내리지 않으면 대부분 '평탄(→)'으로 처리하여 억양의 큰 흐름만 잡도록 시각적 피로도를 줄였다.

## 🚀 최종 결론 (Insight)
> "현재 STT 기술로 한 글자 단위의 완벽한 타임스탬프(Forced Alignment)를 매칭하는 것은 한계가 뚜렷하며, 억지로 구현해도 시각적인 가치가 떨어진다. 오히려 텍스트 전체의 억양 트렌드를 파악하고, 무의미한 노이즈를 쳐내어 직관적인 흐름을 보여주는 것이 사용자(청각장애인) 입장에서 훨씬 유용하다."

## 💻 최종 구현 코드

### 1. Backend (`main.py`)
```python
import static_ffmpeg
static_ffmpeg.add_paths()

from fastapi import FastAPI, UploadFile, File, HTTPException
from fastapi.middleware.cors import CORSMiddleware
import whisper
import librosa
import numpy as np
import shutil
import os
import tempfile
import traceback
import re

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

print("🤖 AI 모델(small) 로딩 중... 한 글자 단위 & 덜 민감한 분석 모드")
model = whisper.load_model("small")
print("✅ 준비 완료!")

def clean_text(text):
    return re.sub(r'[^가-힣0-9a-zA-Z\s.,!?]', '', text).strip()

@app.post("/analyze")
async def analyze_audio(file: UploadFile = File(...)):
    with tempfile.NamedTemporaryFile(delete=False, suffix=".wav") as tmp:
        temp_file_path = tmp.name
        shutil.copyfileobj(file.file, tmp)
    
    try:
        # 1. 텍스트 추출
        result = model.transcribe(
            temp_file_path, 
            word_timestamps=True, 
            language="ko",
            beam_size=5,
            initial_prompt="안녕하세요. 억양 시각화 테스트입니다. 가나다라마바사."
        )
        
        # 2. 오디오 피치 추출
        y, sr = librosa.load(temp_file_path)
        f0, voiced_flag, voiced_probs = librosa.pyin(y, fmin=50, fmax=300, hop_length=256)

        words_data = []
        for segment in result['segments']:
            if 'words' in segment:
                for w in segment['words']:
                    clean_w = clean_text(w['word'])
                    if not clean_w: continue
                    
                    # 다시 한 글자 단위로 쪼개기
                    chars = list(clean_w.replace(" ", "")) 
                    if not chars: continue
                    
                    s_idx = int(w['start'] * (sr / 256))
                    e_idx = int(w['end'] * (sr / 256))
                    word_pitches = f0[s_idx:e_idx]
                    
                    valid_pitches = [p for p in word_pitches if not np.isnan(p)]
                    
                    if len(valid_pitches) < len(chars):
                        for char in chars:
                            words_data.append({"word": char, "pitch": 100.0, "trend": "평탄"})
                        continue
                    
                    # 진짜 목소리 데이터를 글자 수만큼 분할
                    pitch_chunks = np.array_split(valid_pitches, len(chars))
                    
                    for char, p_chunk in zip(chars, pitch_chunks):
                        avg_pitch = np.mean(p_chunk)
                        
                        # 해당 음절의 처음과 끝 주파수 차이 계산
                        diff = p_chunk[-1] - p_chunk[0]
                        
                        # 덜 민감하게 수정: 기준을 5Hz에서 10Hz로 상향 (미세한 떨림은 무시)
                        trend = "상승" if diff > 10 else "하강" if diff < -10 else "평탄"
                        
                        words_data.append({
                            "word": char,
                            "pitch": round(float(avg_pitch), 1),
                            "trend": trend
                        })

        print(f"📊 분석 완료: 한 글자 단위 분할 성공! ({[w['word'] for w in words_data]})")
        return words_data

    except Exception as e:
        traceback.print_exc()
        raise HTTPException(status_code=500, detail=str(e))
    finally:
        if os.path.exists(temp_file_path):
            os.remove(temp_file_path)

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="127.0.0.1", port=8000)
```

<script>
    let mediaRecorder, audioChunks = [];
    const canvas = document.getElementById('visual-canvas'), ctx = canvas.getContext('2d');
    const status = document.getElementById('status'), recordBtn = document.getElementById('record-btn'), stopBtn = document.getElementById('stop-btn');

    recordBtn.onclick = async () => {
        const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
        mediaRecorder = new MediaRecorder(stream);
        mediaRecorder.ondataavailable = (e) => audioChunks.push(e.data);
        
        mediaRecorder.onstop = async () => {
            const audioBlob = new Blob(audioChunks, { type: 'audio/wav' });
            const formData = new FormData();
            formData.append('file', audioBlob, 'test.wav');
            status.innerText = "✨ 글자 위치와 화살표를 계산하는 중...";

            try {
                const res = await fetch('[http://127.0.0.1:8000/analyze](http://127.0.0.1:8000/analyze)', { method: 'POST', body: formData });
                const data = await res.json();
                
                if (data.length > 0) {
                    drawSyllableWave(data);
                    status.innerText = "✅ 시각화 완료!";
                } else {
                    status.innerText = "⚠️ 목소리가 감지되지 않았습니다.";
                }
            } catch (err) {
                status.innerText = "❌ 서버 연결 실패";
            }
        };

        audioChunks = [];
        mediaRecorder.start();
        recordBtn.disabled = true; stopBtn.disabled = false;
        status.innerText = "🔴 녹음 중... (실제 대화하듯 말씀해 보세요)";
    };

    stopBtn.onclick = () => { mediaRecorder.stop(); recordBtn.disabled = false; stopBtn.disabled = true; };

    function drawSyllableWave(data) {
        ctx.clearRect(0, 0, canvas.width, canvas.height);
        
        if (data.length === 0) return;

        const paddingX = 100; 
        const spacing = (canvas.width - paddingX * 2) / (data.length > 1 ? data.length - 1 : 1);
        
        const getY = (hz) => {
            const minF = 60, maxF = 200;
            let y = canvas.height - 150 - ((hz - minF) / (maxF - minF)) * (canvas.height - 250);
            return Math.max(80, Math.min(canvas.height - 100, y));
        };

        // 1. 기준선 (평탄함의 기준)
        ctx.strokeStyle = '#333'; ctx.lineWidth = 2; ctx.setLineDash([10, 10]);
        ctx.beginPath(); ctx.moveTo(paddingX, canvas.height/2); ctx.lineTo(canvas.width - paddingX, canvas.height/2); ctx.stroke();
        ctx.setLineDash([]); 

        // 2. 한 글자 단위 텍스트 그리기
        data.forEach((item, i) => {
            const x = paddingX + (i * spacing);
            const y = getY(item.pitch);

            ctx.shadowBlur = 15;
            if (item.pitch > 130) {
                ctx.shadowColor = '#ff007f';
                ctx.fillStyle = "#fff";
            } else {
                ctx.shadowColor = '#00d2ff';
                ctx.fillStyle = "#e0f7ff";
            }

            // 한 글자이므로 큼직하게 렌더링
            ctx.font = "bold 50px Pretendard";
            ctx.textAlign = "center";
            ctx.textBaseline = "middle";
            ctx.fillText(item.word, x, y);

            // 억양 화살표 (덜 민감하게 반응하여 '→'가 더 자주 나옴)
            ctx.shadowBlur = 0;
            ctx.font = "20px Arial";
            ctx.fillStyle = "#888";
            let arrow = item.trend === "상승" ? "↗" : item.trend === "하강" ? "↘" : "→";
            ctx.fillText(arrow, x, y + 45);
        });
    }
</script>
