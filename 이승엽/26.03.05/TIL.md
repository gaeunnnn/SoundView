# TIL (Today I Learned) - 2026년 3월 5일

## 🔊 프로젝트: 청각장애인을 위한 소리 방향성 기반 햅틱 피드백 시스템

### 1. 개요 및 핵심 아키텍처
청각장애인이 영상 콘텐츠를 시청할 때, 소리의 발생 위치(방향성)와 종류를 인지할 수 있도록 돕는 시스템을 구축함. 단순히 소리의 유무를 알리는 것을 넘어, **특정 환경음을 정밀 추출**하고 **좌우 진폭 차이를 분석**하여 사용자에게 2채널(L/R) 진동 피드백을 전달하는 것이 핵심임.

#### **전체 파이프라인 (Pipeline)**
1.  **Audio Extraction:** 비디오 파일에서 오디오 스트림 추출 (FFmpeg 활용).
2.  **1st Pass (YAMNet):** 전체 오디오 데이터에서 환경음(Environmental Sound)이 발생하는 구간을 1차적으로 탐지. (예: 05:20~05:25 구간에 'Car Horn' 발생)
3.  **2nd Pass (AudioSep):** 탐지된 구간에 대해 텍스트 쿼리("Car Horn")를 입력하여 배경 소음을 제거하고 해당 소리만 정밀 분리.
4.  **Stereo Analysis:** 분리된 오디오의 L/R 채널 데이터를 분석하여 진폭(Amplitude) 차이를 계산.
5.  **Haptic Mapping:** 계산된 진폭 비율을 바탕으로 프론트엔드(JavaScript)에 진동 세기 데이터를 전달.

---

### 2. 오늘 시도한 기술적 구현 (Technical Implementation)

#### **[Python Backend]**
*   **`yamnet_detector.py`:** YAMNet 모델을 활용하여 오디오 스트림에서 소리 분류 및 구간 탐지 로직 구현. 현재 특정 구간에서 환경음이 포착되는 단계까지 성공.
*   **`audiosep_stereo_analyzer.py`:** AudioSep 모델을 통해 텍스트 기반 소리 분리를 시도. (현재 의존성 문제로 디버깅 중)
*   **`amplitude_analyzer.py`:** `librosa` 또는 `scipy.io.wavfile`을 사용하여 스테레오 오디오의 각 채널별 RMS(Root Mean Square) 진폭을 계산하는 알고리즘 작성.
    *   *로직:* `Ratio = (L_amplitude - R_amplitude) / (L_amplitude + R_amplitude)` 값을 통해 소리의 치우침 정도를 -1.0(왼쪽 극단) ~ 1.0(오른쪽 극단) 사이로 정규화.

#### **[Frontend JS]**
*   **`haptic_test.js`:** `navigator.vibrate()` API를 활용한 진동 테스트 코드 작성. 
*   **Haptic UI:** 백엔드에서 전송된 진폭 데이터를 실시간으로 수신하여 화면에 시각화(Gauge)하고, 디바이스의 진동 모터를 제어하기 위한 인터페이스 준비.

### 3. 주요 이슈 및 해결 과정 (Troubleshooting)

#### **🚨 문제 1: 환경 구축 및 라이브러리 의존성 충돌**
- **상황:** AudioSep 구동을 위해 필요한 `torch`, `torchaudio` 버전과 YAMNet 구동 환경 간의 의존성 충돌 발생. 
- **원인:** 특정 모델은 CUDA 11.x 환경을 요구하나, 다른 라이브러리는 최신 환경에서만 작동하는 문제.
- **해결 방안:** `conda` 환경을 분리하거나, `docker`를 활용하여 각각의 모델을 독립된 컨테이너에서 마이크로서비스 형태로 운영하는 방안 검토 중.

#### **✅ 성과: YAMNet 기반 소리 구간 탐지 성공**
- **내용:** 전체 긴 영상에서 모든 구간을 분석할 필요 없이, 소리가 발생하는 유의미한 구간만 추출하여 AudioSep의 연산 부하를 줄이는 전처리 단계 최적화 완료.
