📌 LLM 작동 방식 및 원리 정리
1️⃣ LLM이란?

대규모 텍스트 데이터를 학습한 언어 모델

이전 단어들을 기반으로 다음에 올 단어를 예측하는 방식으로 작동

확률 기반 생성 모델

⚙️ 2️⃣ LLM 작동 과정
① Tokenization (토큰화)

문장을 작은 단위(Token) 로 분리

보통 Byte Pair Encoding(BPE) 방식 사용

🔹 BPE 원리

단어를 문자 단위로 분해

가장 자주 등장하는 문자 쌍을 병합

이 과정을 반복하여 서브워드 단위 생성

➡ 희귀 단어도 처리 가능
➡ 단어 사전 크기 효율적으로 관리

② Embedding (벡터화)

토큰을 숫자 벡터로 변환

의미가 비슷한 단어는 벡터 공간에서 가까움

예:

king - man + woman ≈ queen
③ Transformer 구조

LLM은 Transformer 아키텍처 기반

핵심 요소
🔹 Self-Attention

문장 내 모든 단어를 서로 비교

어떤 단어가 중요한지 가중치 계산

예:

"나는 사과를 먹었다. 그것은 맛있었다."
→ "그것"이 "사과"를 가리킨다는 관계 파악

🔹 Multi-Head Attention

여러 관점에서 동시에 관계 분석

🔹 Feed Forward Network

Attention 결과를 비선형 변환

④ 다음 토큰 예측

모델은 다음 토큰의 확률을 계산

나는 오늘 밥을 → [먹었다(0.7), 먹을까(0.2), 먹고(0.1)]

확률 기반 선택 후 반복 생성

🧠 3️⃣ 학습 방식
📍 Pre-training

대량의 텍스트로 다음 단어 예측 학습

📍 Fine-tuning

특정 목적에 맞게 추가 학습

📍 RLHF

인간 피드백 기반 보정

⚠️ 4️⃣ 한계점

❌ Hallucination (사실과 다른 정보 생성)

❌ Bias (학습 데이터 편향 반영)

❌ 최신 정보 반영 한계

❌ 복잡한 추론 한계

❌ 윤리적 문제 가능성
