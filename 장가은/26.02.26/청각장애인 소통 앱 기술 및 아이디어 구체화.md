## 청각장애인 비청각장애인 소통 앱 기획 정리

## 1. 프로젝트 개요

청각장애인과 비청각장애인 간의 전화 소통에서 발생하는 문제를  
AI 음성 기술을 활용해 해결하는 실시간 통화 기반 앱.

### 해결하고자 하는 문제

- 감정이 제대로 전달되지 않음  
- 음성의 높낮이(억양) 정보가 전달되지 않음  
- 청각장애인의 발음 문제로 의사 표현이 어려움  


## 2. 주요 기능

## 2-1. 비청각장애인 → 청각장애인

### (1) 음성 높낮이 시각화

#### 목적  
음성의 억양과 강세를 시각적으로 전달

#### 처리 흐름  
음성 입력  
→ STT 변환  
→ Pitch(Hz) 분석  
→ 텍스트 시각화 반영  

#### UI 표현 방식

- 높은 톤 → 글자 크기 확대  
- 낮은 톤 → 글자 크기 축소  
- 강한 발화 → Bold 처리  
- 강조 구간 색상 변화  


### (2) 감정 분석 + 이모지 + 퍼센트 게이지

#### 목적  
말의 감정을 직관적으로 전달

#### 처리 흐름  
음성 입력  
→ 감정 분석 모델  
→ 확률 기반 감정 분류  

#### 출력 예시

- 😡 화남 72%  
- 😊 기쁨 18%  
- 😢 슬픔 10%  


## 2-2. 청각장애인 → 비청각장애인

### (1) 텍스트 기반 음성 변환 (TTS)

청각장애인이 텍스트를 입력하면  
자연스러운 음성으로 변환하여 전달


## 3. 핵심 고민 사항

## 3-1. 개인 음성 복제 가능 여부

### 문제점

- 음성 클로닝은 최소 1~5분 이상의 깨끗한 발화 데이터 필요
- 발음이 불명확하면 학습 데이터 정렬이 어려움
- 발성을 거의 하지 못하는 경우 학습 자체가 불가능

### 결론

완전한 개인 음성 복제는 현실적으로 매우 어려움.


## 3-2. 목소리 톤만으로 학습 가능 여부

### 한계

음성 모델은 단순 톤이 아니라:

- 음색 (Timbre)
- 발화 습관
- 억양 패턴
- 발음 특성

을 종합적으로 학습해야 함.

### 결론

톤 정보만으로는 개인화 음성 생성이 어렵다.


## 4. 현실적인 해결 전략

## 전략 1. 일반화된 음성 선택 방식

- 남성 / 여성
- 유아 / 청년 / 중년
- 차분한 톤 / 밝은 톤

선택된 화자 기반으로 TTS 출력


## 전략 2. 감정 제어 TTS 적용 (추천)

텍스트 입력  
→ 화자 선택  
→ 감정 선택  
→ 감정 반영 음성 출력


## 5. 최종 방향성

완전한 개인 음성 복제 대신  
일반화된 음성 + 감정 제어 TTS 기반 접근이

- 기술적 현실성
- 시연 안정성
- AI 음성 도메인 적합성

측면에서 가장 합리적인 전략이다.
