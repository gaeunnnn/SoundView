## 로그인 페이지 UI 설계 및 구현

- AI 영상 자막화 서비스(SoundSee) 로그인 페이지 UI 설계
- 영상 자막 적용 전(Before) / 적용 후(After) 비교 화면을 통해 서비스 기능 직관적으로 표현
- “눈으로 들으세요” 슬로건을 통해 청각장애인을 위한 서비스 목적 강조
- 카카오 소셜 로그인 버튼을 적용한 간편 로그인 구조 설계
- 서비스 기능을 한눈에 이해할 수 있도록 전체 UI 레이아웃 구성

## 메인 페이지 UI 설계

- 로그인 이후 사용자 영상 관리 화면(드라이브 형태 UI) 설계
- 업로드된 영상 목록을 카드 형태로 보여주는 영상 관리 인터페이스 구성
- 영상별 썸네일, 재생 시간, 생성된 자막 여부 등을 확인할 수 있도록 UI 설계
- 좌측 사이드바를 통해 드라이브, 자막 생성 등 주요 기능에 접근 가능하도록 구성
