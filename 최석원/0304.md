2026.03.04 TIL — AI 소리 인식/자막 생성 페이지 UI·플로우 정리
1) 오늘 한 일

전체 화면(Full Screen) 편집 UX 요구사항을 명확히 정리했습니다.

전체 화면 진입 시에도 이모티콘 토글 버튼이 영상 영역 내부에 포함되어야 하고,

‘인식된 소리’ 탭이 전체 화면 안에서 펼치기/접기 가능해야 한다는 기준을 확정했습니다.

레이아웃 구조 변경 방향을 정리했습니다.

기존처럼 영상 아래가 아니라, 우측 사이드바에 ‘인식된 소리’ 영역을 배치하는 구조로 전환합니다.

영상 업로드 및 자막 변환 완료 시점에 **‘인식된 소리’ 탭 + 체크박스 + 타임라인별 토글(예: 바람소리)**가 정상적으로 노출되어야 합니다.

상단 바/컨트롤 구성 개선 요구사항을 반영했습니다.

영상 영역 우측 상단(“결과 플레이어” 텍스트 우측)에 ‘저장하기’ 버튼을 추가합니다.

상단 바의 공유/다운로드 버튼은 제거합니다.

**저장 플로우(편집 완료 → 저장 → 메인 복귀 → 재생)**를 정의했습니다.

“저장하기” 클릭 후 메인 화면으로 돌아가며,

방금 수정한 영상이 메인에서 즉시 재생 가능해야 합니다.

AI 자막 생성 페이지에서 좌측 사이드바를 숨김 처리하는 방향을 확정했습니다.

2) 배운 점 / 정리된 원칙

“전체 화면”은 단순 확대가 아니라, 편집 기능의 컨텍스트(토글/탭/체크 상태)를 유지한 채 레이아웃만 재배치하는 문제로 보는 게 맞습니다.

사용자 관점에서 중요한 것은 “기능이 어디에 있느냐”보다, 편집 흐름이 끊기지 않고(탭/토글/선택 상태 유지) 저장까지 자연스럽게 이어지는가입니다.

저장 버튼 위치는 “상단 바”보다 결과(영상) 컨텍스트에 붙이는 편이 인지적으로 더 명확합니다. (“내가 편집한 결과를 저장한다”의 의미가 즉시 전달됨)

3) 이슈 / 현재 문제 인식

과거 버전에서 있던 ‘인식된 소리 탭 + 체크박스 + 타임라인별 토글’ 동작이 현재 버전에서 깨져 있음이 확인되었습니다.

전체 화면에서 UI 요소들이 “레이어/영역” 기준으로 재배치되지 않으면,

토글/탭이 화면 밖으로 밀리거나

편집 조작이 불가능해지는 UX 문제가 발생할 수 있습니다.

4) 해결 방향(설계 관점)

화면을 “3영역”으로 고정해 사고를 단순화합니다.

영상 영역(중앙): 재생/자막/이모티콘 토글 포함

우측 사이드바: 인식된 소리 탭, 체크박스, 이벤트 리스트(타임라인)

상단 최소 컨트롤: 불필요 버튼 제거, 저장만 핵심 위치로 이동

저장 시점에 필요한 것은 “파일 저장”뿐 아니라, 메인 화면에서 해당 결과를 다시 로드할 수 있는 식별자/상태 관리입니다.

예: 저장 결과의 URL/ID를 라우팅 상태나 스토리지에 남겨 메인에서 재생 연결

5) 다음 할 일(체크리스트)

전체 화면에서도 인식된 소리 탭이 접기/펼치기로 동작하도록 UI 구조 확정

“인식된 소리”를 우측 사이드바로 옮긴 뒤에도

체크박스 선택/해제

타임라인별 이벤트 토글

선택 상태 유지
가 정상 동작하는지 회귀 점검
