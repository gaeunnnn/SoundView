주변음(환경음) 분류/감지 모델 조사 및 요구사항 정리
1) 오늘 한 일

“사람 말소리 분리(추출)”가 아니라, **겹쳐 들리는 상황에서도 각각 어떤 소리인지 ‘구분/탐지’**하는 방향으로 요구사항을 재정의했습니다.

집 안에서 실제로 겹치기 쉬운 소음 상황을 가정해, **감지 우선순위(위험/안전 관련)**를 정리했습니다.

소리 분류/탐지 모델이 잘하는 것 vs 잘 못하는 것을 기준으로, 프로젝트 리스크를 사전에 점검했습니다.

라벨링(학습 데이터 구성)의 의미를 “하나하나 소리를 학습시키는 것”이 아니라, 목표 카테고리를 정하고(라벨 체계) 데이터를 그 체계로 묶어가는 과정으로 이해를 정리했습니다.

2) 배운 점 (핵심 인사이트)

**겹친 소리 분리(source separation)**와 **소리 인식(분류/탐지)**는 목표와 난이도가 다릅니다.

분리는 “각 소리를 분리된 트랙으로 뽑는 것”

인식은 “현재 구간에 어떤 이벤트/카테고리가 존재하는지 확률로 판단하는 것”

현실 환경에서 “대화/TV/음악” 같은 강한 소리는 다른 소리를 쉽게 덮기 때문에, 모델이 **약한 이벤트(물 끓는 소리, 작은 문 소리 등)**를 놓칠 수 있습니다.

라벨을 너무 촘촘하게 나누면(예: ‘접시가 유리인지 도자인지’), 데이터가 부족해져 성능이 흔들립니다.
→ 실사용 관점에서는 **“의미 있는 범주로 묶기(라벨 그룹화)”**가 중요합니다.

3) 잘 되는 케이스 / 잘 안 되는 케이스 정리

잘 되는 편

음색/패턴이 뚜렷한 소리:

경보음(알람, 사이렌), 초인종/벨, 박수/타격음, 개 짖음 등

배경이 조용하고 단일 이벤트가 선명한 구간

어려운 편

소리가 동시에 여러 개 겹치고, 특히 사람 말소리가 강할 때

서로 스펙트럼이 비슷한 생활 소음들:

주방(식기, 물소리, 환풍기, 냉장고 모터 등) 같이 금속성/노이즈성 소리가 혼재한 환경

“위험 소리”라도 소리가 작거나 지속적으로 깔리는 환경음에 묻히는 경우(예: 멀리서 들리는 경보기)

4) 집에서 겹치기 쉬운 “위험/주의” 상황 예시

주방: 물 끓는 소리 + 후드/환풍기 + 그릇/수저 소리 + 사람 대화

세탁/욕실: 샤워기/물소리 + 환풍기 + 문 열림/닫힘

거실: TV/음악 + 초인종/노크 + 휴대폰 알림

사고 상황: 물건 떨어짐/파손(유리 깨짐 포함) + 사람 움직임/대화

→ 결론적으로, “완벽 분리”보다 중요 이벤트(경보/파손/끓음 등)를 놓치지 않는 탐지가 우선순위가 될 수 있다고 판단했습니다.

5) 다음 액션 아이템

목표 라벨을 ‘실사용 중심’으로 15~30개 수준으로 1차 정의
(예: 연기경보기/초인종/문열림·닫힘/유리깨짐/물끓음/아기울음/사이렌 등)

짧은 테스트 클립(10~30초)로 단일 소리 vs 겹침 소리를 각각 준비해, 모델이 놓치는 패턴을 빠르게 확인

평가 지표를 단순화:

Top-3 포함률, 오탐/미탐, 겹침 상황에서의 미탐률

6) 회고

오늘은 “무엇을 만들지”보다 무엇을 정확히 감지해야 하는지가 더 중요하다는 점을 명확히 했습니다.

라벨을 촘촘히 늘리기보다, 실제 사용자(청각장애인/무음 환경 사용자)에게 의미 있는 이벤트 중심으로 설계하는 쪽이 현실적인 접근이라고 느꼈습니다.
